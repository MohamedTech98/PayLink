# Architecture Decision Records

Create at least three ADRs as required by the project brief. Each ADR should compare at least two options, explain trade-offs, record the decision, and state consequences.

Suggested topics:
1. Architecture style: layered modular monolith vs hexagonal modular monolith.
2. Module communication: direct application interfaces vs in-process domain events.
3. Data ownership: shared database with module-owned tables vs separate databases.
